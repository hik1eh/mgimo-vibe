# Первый промпт агенту разработки

> Ты разрабатываешь конкурсный прототип «Цифровой деканат». Прочитай `AGENTS.md`, `docs/00-decisions.md`, `docs/01-product.md`, `docs/03-technical.md`, `docs/04-backlog.md` и первые проверки в `docs/05-acceptance.md`. В начале определи, пуст ли репозиторий, и сообщи краткий план. Затем начни реализацию T01–T03. Сервер FastAPI. Для пустого проекта используй React + TypeScript + Vite и PostgreSQL, SQLAlchemy, Alembic. Для существующего проекта проверь его структуру и используй пригодные компоненты. Сделай воспроизводимый запуск, миграции, два вымышленных студенческих аккаунта разных факультетов и сотрудника одного факультета. 
>
> Первый рабочий сценарий. Студент входит, видит свой профиль и заказывает справку об обучении. После перезагрузки заявка остаётся в списке. Сотрудник открывает очередь своего факультета, берёт заявку в работу, при необходимости запрашивает уточнение и завершает заявку. Студент отвечает в карточке, а после завершения получает уведомление и может скачать демонстрационную справку. Для первой итерации можно использовать простое оформление, работающее и на телефоне.
>
> После реализации запусти доступные проверки, включая отказ в доступе к чужой заявке и документу, и коротко опиши команды и фактические результаты. Дополни README запуска. Отдельно перечисли, что пока не проверено и что относится к T04–T07. Рабочие пароли и секреты держи в окружении, демодоступы для жюри передаёт команда.
