## Реально выполненные проверки

```powershell
npm.cmd --prefix frontend run build
docker compose -p dekanat-qa -f compose.qa.yaml up --build -d --wait db app
docker compose -p dekanat-qa -f compose.qa.yaml build browser
docker compose -p dekanat-qa -f compose.qa.yaml exec -T app python -m app.qa --reset-test-data
docker compose -p dekanat-qa -f compose.qa.yaml run --rm --no-deps browser npx playwright test cabinet-header.spec.ts layout.spec.ts compatibility.spec.ts
```

Сборка TypeScript/Vite успешна локально и в Docker. **11 passed за 93,8 с**, 0 skipped/unexpected/flaky:

- Четыре новых теста: 360/768/1440/1916, четыре фото, заголовки и активные пункты, переходы без перезагрузки документа, Back/reload, уведомления, профиль и выход.
- Четыре layout-прогона: 360/390/768/1440, 13 страниц каждой ширины, обе роли, отсутствие горизонтального overflow и axe на 52 экранах.
- Один прогон клавиатуры, фокуса, ленты, пустых расписания и семестра.
- Два прогона совместимости: WebKit 360 и Firefox 1440, переходы по разделам и создание заявки с сохранением после reload.

Ошибок pageerror нет. Отчёт: `artifacts/browser/cabinet-header/results.json`. Дополнительный визуальный захват подтвердил ширину документа 1440 при viewport 1440 с базовым текстом 200%; `visual-metrics.json`, `text-200-1440.png`. Первый запуск захвата не нашёл HTML из-за пути вне смонтированного `artifacts/browser`; путь исправлен, повторный захват успешен. Проверки приложения в первом запуске захвата не выполнялись и не засчитывались.
