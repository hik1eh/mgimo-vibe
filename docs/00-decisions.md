# Решения для разработки

## Подтверждено владельцем проекта

- Один вымышленный вуз. Рабочее название продукта — «Цифровой деканат». Два вымышленных факультета и по одной группе для демонстрации.
- Визуальное направление сочетает светлый современный кампусный интерфейс и более смелые акценты. Студенческая главная выразительна, рабочая очередь сотрудника спокойнее. Цвет, типографику и плотность можно менять через токены после первой визуальной итерации.
- Полноценный кабинет сотрудника. В рабочий объём входят очередь и обработка справок, запрос уточнений, выдача демонстрационного PDF, управление объявлениями факультета или группы, правка и отмена занятий в пределах факультета.
- Десктопная навигация по центру сверху. Под ней на главной студента — горизонтальная лента с ручным перелистыванием. На телефоне карточки со свайпом и доступными кнопками.
- Сервер — FastAPI. Вымышленные интервью и анкета используются как моделирование.

## Рабочие настройки, которые можно поменять

| Вопрос | Настройка для старта |
|---|---|
| Фронтенд | React + TypeScript + Vite. |
| Хранение | PostgreSQL, SQLAlchemy, Alembic. |
| Название вымышленного вуза | «Университет Северного кампуса». Имя и подпись настраиваются в одном месте. |
| Визуальные акценты | Тёплый светлый фон, насыщенный синий для основных действий, дополнительный цвет для заметных акцентов. Использовать крупное время ближайшей пары и выразительную типографику. |
| Демороли | Студент А, студент Б, сотрудник факультета А. Общевузовские новости заранее загружаются. |
| Область сотрудника | Управление заявками, объявлениями и расписанием своего факультета. Успеваемость и профили студентов демонстрируются через демонаполнение. Дополнительные роли и редактирование оценок можно обсудить отдельно. |
| Размещение | Конкретный хостинг команда выбирает по доступности из России без VPN и наличию постоянной базы. |

## Два действия сотрудника для показа

1. Изменить аудиторию отдельной демонстрационной консультации своей группы с 305 на 412. Сохранить историю переноса и предложить опубликовать связанное объявление. Форма объявления предзаполняет группу и ссылку на занятие. Студент А видит карточку и актуальную аудиторию. Студент Б видит собственную ленту.
2. Взять справку в работу, запросить уточнение, получить ответ, завершить заявку и открыть готовый PDF под студенческим аккаунтом.
