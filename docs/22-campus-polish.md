# Кабинет Северного кампуса · проверка правок

## Что изменилось

- На входе восстановлена объёмная шапочка с золотой кисточкой. На телефоне модель занимает прежнее компактное место. При уменьшенном движении показывается неподвижный ракурс, при отключённом WebGL используется изображение.
- Лента новостей смещает карточки на соседние позиции за 270 мс после нажатия стрелки. Телефон использует плавную прокрутку и свайп. Обводка напоминает о переносе и гаснет после наведения или открытия. Прочитанное изменение хранится в браузере для конкретного аккаунта и версии занятия.
- Демонаполнение даёт две учебные недели для каждой группы, с лекциями, семинарами, практиками и вымышленными преподавателями. Сохраняются прежние записи и их правки. У каждой группы собственные данные, доступ проверяет сервер.
- Бейдж по центру при входе на страницу. На широком экране он сдвигается влево при открытии карточки, на телефоне данные раскрываются ниже него. Девять сведений и редактирование контактов работают через личный профиль. Возраст рассчитывается по дате рождения, номер билета выдаётся только в личном кабинете.
- Панель навигации и баннер используют один тёмно-синий фон. Информация о прототипе и вымышленных данных находится в конце страницы на полупрозрачной серой полосе.
- Детали фасадов и предметов построены из объёмных мешей. Ракурсы «Главный вход», «Учебные корпуса» и «Внутренний двор» доступны по кнопке «Кампус в 3D» в разделе «Сегодня» и в маршруте по Северному корпусу. Поэтажная схема сохраняет навигацию до двери.

## Проверка

```powershell
npm.cmd --prefix frontend test
docker compose -p dekanat-qa -f compose.qa.yaml up --build -d --wait db app
docker compose -p dekanat-qa -f compose.qa.yaml build browser
docker compose -p dekanat-qa -f compose.qa.yaml exec -T app python -m app.qa --reset-test-data
docker compose -p dekanat-qa -f compose.qa.yaml run --rm --no-deps browser npx playwright test auth.spec.ts cabinet-header.spec.ts campus-polish.spec.ts compatibility.spec.ts evidence.spec.ts final-mvp.spec.ts layout.spec.ts premium.spec.ts states.spec.ts student-redesign.spec.ts workflow.spec.ts
```

Серверные тесты используют `dekanat_mvp_test` и команду `python -m app.check` с `TEST_DATABASE_URL`. Команды выделенного запуска приведены [в предыдущем отчёте](21-final-mvp.md#локальный-запуск-и-проверка).

Первый браузерный прогон дал 16/20. Блок кабинета сужался на широком экране и растягивался на телефоне из-за автоматических отступов во flex-контейнере. Основной области задана полная ширина. Три проверки мобильного входа ожидали отсутствие модуля шапочки, который теперь требуется для её вращения. Исправлено условие о наборе ресурсов. Загрузка семи фото и шрифта Allura по-прежнему проверяется только в десктопной композиции.

Для резервного отображения сняты десять кадров WebGL размером 900×400. Снова снять их можно командой `docker compose -p dekanat-qa -f compose.qa.yaml run --rm --no-deps -e MODEL_OUTPUT=/artifacts/campus-polish/models browser node capture-models.cjs`. ## Фактические прогоны

Сборка TypeScript/Vite в Docker прошла. 40 тестов PostgreSQL и 12 модульных тестов успешны. `alembic check` подтвердил соответствие схемы. В журнале остались прежнее предупреждение AnyIO и предупреждение Vite о размере динамического модуля Three.js.

Общий прогон дал 53/57. Повтор дал 9/10 с успешной проверкой длинного ФИО, записи кадров с пульсирующей рамкой, изменения и отмены занятия. Для теста выбрано занятие по идентификатору, а ожидание кадров ограничено конечными переходами. Последняя проверка в повторе выявила старый оттенок у двух страниц. Удалена отдельная настройка фона этих страниц.

Финальный прогон дал 6/6, включая единый фон, раскрытие бейджа, жест на телефоне и три ракурса. Проверка перезапуска `persistence.spec.ts` прошла. До и после перезапуска сравнивались сессии обеих ролей и их данные. С учётом повторов и перезапуска прошли 58 уникальных браузерных сценариев.
