# Приёмка прототипа

Фиксировать фактический результат, URL или сборку, дату, браузер и устройство. Указывать «Не проверено», если тест не запускался. Прогоны выполнять на вымышленных тестовых аккаунтах.

| ID | Проверка | Ожидаемый результат |
|---|---|---|
| A01 | Войти под студентами А и Б и сотрудником, проверить ошибку входа и выход. | Роли попадают в нужные интерфейсы. У студентов разный профиль. Сессия переживает обновление страницы и прекращается после выхода. |
| A02 | Студент А с телефона находит перенос через ленту и открывает занятие. | Видит старую и новую аудиторию, дату и время. Совпадают лента и расписание. |
| A03 | Открыть ленты А и Б, «Все объявления» и прямую ссылку на групповое объявление от имени Б. | У обоих есть общевузовская запись. Б не получает содержимое чужого объявления. |
| A04 | Открыть «Сегодня», неделю и день без занятий. | Расписание показывает данные своей группы. Пустое состояние объясняет, что занятий нет. |
| A05 | Проверить следующий зачёт и дисциплину с ожидаемым результатом. | Студент может отличить оба состояния и понять прогресс сессии. |
| A06 | Подать справку, обновить страницу, обработать из второй сессии, открыть уведомление и скачать PDF. | Сохраняются номер, история, статус и уведомление. PDF содержит пометку о демонстрационном образце. |
| A07 | Студент Б открывает URL заявки, PDF и персонального уведомления А. Сотрудник открывает заявку другого факультета по прямому адресу. | Сервер закрывает доступ и не возвращает содержимое. |
| A08 | Сотрудник задаёт вопрос, студент отвечает, сотрудник продолжает. | Вопрос и ответ видны в истории. Студент понимает следующий шаг. Уточнение можно обработать с телефона. |
| A09 | Сотрудник публикует объявление своей группе, редактирует, снимает с публикации и пытается выбрать чужую группу. | Объявление появляется у адресатов, обновляется после правки и исчезает после снятия. Чужая аудитория отклоняется. |
| A10 | Сотрудник меняет аудиторию отдельной демонстрационной консультации своей группы, отменяет другое занятие и пытается изменить занятие чужого факультета. | Разрешённое изменение показывает прежнюю и актуальную аудиторию. Отменённое занятие помечено. Чужое занятие закрыто для изменения. |
| A11 | Проверить экраны при 360, 390, 768 и 1440 px, клавиатуру и длинные подписи. | Основные действия доступны. Горизонтальная прокрутка страницы отсутствует, фокус видим, карточки ленты доступны с клавиатуры. |
| A12 | Воспроизвести пустые состояния, сбой отправки, истечение сессии и повторное нажатие. | Понятные сообщения. Введённый текст сохраняется при исправимой ошибке. Дубли заявки или перехода при повторе не появляются. |
| A13 | Проверить публичный URL из России без VPN, затем вход всеми ролями и полный путь по заявке. | Сайт доступен по HTTPS, а данные сохраняются после обновления. Зафиксирована дата внешней проверки. |
| A14 | Открыть ссылку на код и отчёт в приватном окне. Проверить состав отправки. | Жюри имеет доступ к исходникам и документу. Ссылка на прототип и три демоаккаунта готовы для комментария капитана. |
