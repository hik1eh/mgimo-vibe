## Исходное состояние и решения

В `E:\mgimo-vibe` обнаружен пакет требований `dekanat-handoff/`; исходников, зависимостей и Git не было. Корнем приложения выбрана эта папка. Прочитаны AGENTS и документы 00, 01, 02, 03, 04, 05. Стек из требований: React 19, TypeScript, Vite; FastAPI, SQLAlchemy 2, Alembic, PostgreSQL. Приложение отдаёт собранный фронтенд и API на одном origin. Docker Compose хранит БД в томе. Пакеты зафиксированы в npm lock и Python requirements.lock. PostgreSQL 17 указан для Compose; реальный локальный прогон выполнен на установленной 18.3, поскольку Docker Engine остановлен. Python Store alias не запускался; использован установленный Python 3.13.5.

T02: два факультета, две группы, три вымышленных пользователя. Согласованность группы и факультета защищена составным внешним ключом, роль и обязательные поля — CHECK. Argon2id, случайная серверная сессия с хешем токена, сроком и отзывом, HttpOnly cookie, Origin и CSRF включая login/logout. Пароли сгенерированы только в игнорируемый `.env`; не выведены и не включены в код.

T03: форма, список, прямая карточка, профиль, факультетская очередь с фильтрами/поиском, история, вопрос и ответ, готовность, личные уведомления с прочтением, PDF. Идемпотентность заказа — UUID одной отправки; версия заявки — защита переходов при конкуренции. Изменение, событие, уведомление и документ сохраняются одной транзакцией. Черновики формы/ответа хранятся в sessionStorage; пароль не сохраняется. Статусы подписаны текстом, формы имеют подписи, предусмотрены ошибки/пустые списки и CSS для телефона. ## T05 — адресная лента и инструменты сотрудника

13 ноября 2026, Москва. Прочитаны актуальные AGENTS, решения, продукт, T05, UI, техническая спецификация и приёмка. Существующие роли, заявки, сессии, учебные записи и ограничения файлов сохранены. Дополнительные агенты не запускались.

Добавлена миграция `809243ec75e2`: объявления, адресность, окно публикации, версия и ключ отправки. Составные внешние ключи связывают группу с факультетом и занятие с группой. CHECK ограничивает аудиторию и состояния. Сотрудник управляет только факультетскими/групповыми сообщениями своего факультета; университетские загружаются seed. Чужое объявление, черновик, будущее или истёкшее сообщение не выдаётся студенту даже по прямому id.

Серверные маршруты поддерживают создание, публикацию, правку и снятие объявления. Создание защищено уникальным ключом с отпечатком исходного тела; точный повтор не создаёт копию. Правки версионные: параллельный проигравший получает 409. Все изменения проверяют Origin и CSRF. Для связанного объявления разрешена только группа занятия; текущая аудитория, время и отмена загружаются из самой записи занятия. Это устраняет устаревшие поля карточки при повторном переносе.

В расписании сотрудника есть поиск по дисциплине/преподавателю, группа и диапазон дат. Доступ к отдельному занятию проверяет факультет. Правка времени/корпуса/аудитории или отмена сохраняет состояние и before/after с причиной и автором одной транзакцией; версия защищает от дубля истории. Отменённая запись доступна для просмотра и не редактируется повторно. Ответ даёт данные для формы связанного сообщения; публикация остаётся отдельным явным действием. Дисциплина, преподаватель и группа этим маршрутом не меняются.

Во фронтенде студент по умолчанию попадает на «Сегодня». Под меню — ручная горизонтальная лента с кнопками, scroll-snap и обработкой стрелок клавиатуры; ниже — ближайшее занятие, заявки с нужным уточнением/готовой справкой и предстоящий зачёт. Доступны все объявления и прямая карточка. В уведомлениях сохранены личное прочтение и ссылка на заявку, добавлены адресные сообщения и учебное напоминание. На телефоне предусмотрена нижняя навигация, сверху профиль и уведомления с числом личных непрочитанных. Эти взаимодействия реализованы, но браузером не проверены.

Сотрудник получает очередь по умолчанию, разделы объявлений и расписания, формы с сохранением черновика в sessionStorage, сравнение с текущими параметрами и историю. После переноса форма объявления предзаполняет группу и ссылку. При конфликте серверная версия обновляется отдельно, введённый текст не затирается автоматически. Добавлены ошибки и повторная загрузка, пустые списки, статусы словами, поля с подписями. Проверка удержания текста/фокуса в браузере остаётся невыполненной.

Seed добавляет четыре действующие записи: общевузовскую, две факультетские и закреплённую групповую со ссылкой на перенос. Повторный seed не возвращает снятые публикации, не затирает текст или правки расписания. Окно показа новостей сравнивается с текущим временем сервера; замороженная учебная дата продолжает использоваться только для демонстрационного учебного дня.

### Наблюдения и исправления T05

1. Alembic autogenerate поставил создание нового составного UNIQUE после таблицы с внешним ключом на него. Первая миграция завершилась отказом PostgreSQL и откатом транзакции. Порядок исправлен: UNIQUE до дочерней таблицы, при downgrade — после её удаления. Повторный upgrade, чистый цикл миграций в тестах и alembic check успешны.
2. Первый расширенный прогон дал 34 passed / 1 failed: в новом тесте забыта `.json()` у HTTP Response. Исправлен тестовый код; повторный полный прогон — 35 passed. Прежние 25 проверок сохраняются.
