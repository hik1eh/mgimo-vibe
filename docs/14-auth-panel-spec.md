# Панель входа по новому видеореференсу

15 ноября 2026. Последние указания владельца: убрать паузу целиком и подпись «Ближе к знаниям. Ближе друг к другу.», сделать отметку о прототипе меньше/ниже, подобрать современную типографику и повторить характер панели из `2026-11-15 01-37-14.mp4`.

Перед реализацией видео разобрано в 30 fps: 447 кадров, 14,9 с. Контактный лист и исходные кадры 3,13/5,5/8,6 с просмотрены; файлы хранятся в системном Temp вне проекта. Видна компактная тёмная карточка, два луча из верхних углов к активному полю, тёплая подсветка фокуса, красное состояние ошибки и светлая кнопка.

## Решение до реализации

- Сохранить full-bleed 65/35, поток фото и модель билета. Удалить UI паузы и связанное состояние. Системное reduced motion, остановка скрытой вкладки/сцены остаются. Непрерывная декоративная анимация без ручного управления — явное требование владельца.
- Правые 35% — глубокий navy-фон и компактная карточка с мягким контуром/радиусом, inset-полями, белой кнопкой. Использовать существующие AuthPanel, API, ErrorBox, CSS и растровый asset луча. Регистрацию/третье поле из референса не добавлять.
- Два луча направляются на фактическую позицию выбранного input. Переход transform/opacity около 500 мс, текущее общее easing. При blur лучи гаснут; при ошибке краснеют. Не приглушать контент до нечитаемого состояния, как в отдельных кадрах showcase.
- Типографика входа: Manrope для заголовков/названия кампуса, Golos Text для интерфейса. Локальные variable-файлы и OFL-лицензии из официального Google Fonts; без внешних запросов к шрифтовым сервисам во время работы приложения. Остальные экраны используют прежние токены.
- Отметка о прототипе — мелкий спокойный footer у нижнего края правой панели. Подпись слева и кнопка паузы отсутствуют.
- До 1000 px — только панель, без WebGL/кампусных фото; световые анимации отключены на мобильном и при reduced motion. На 360 px сохранить 44+ px действия, видимый фокус и отсутствие горизонтального overflow.

## Реализация и источники шрифтов

Код и браузерные проверки зафиксированы в `b369e0b`.

AuthPanel сохраняет управляемые props и общий вход при истечении сессии. ResizeObserver измеряет настоящий input, лучи поворачиваются и масштабируются к нему. Растровый asset `auth-light.webp` переиспользован как luminance mask: золотой цвет задаёт токен, красный слой появляется через crossfade. Это устраняет ненадёжный hue-rotate, который в первом сравнении давал жёлтый свет ошибки. Срок перехода — `--auth-light: 500ms`, easing — существующий `--ease-out`. Движение полей/размеров не анимируется. В WebGL добавлено ожидание текстуры перед показом canvas, чтобы не показывать светлую необработанную обложку на медленной загрузке.

Новые токены в `tokens.css`: семейства шрифтов, фон/контур карточки и полей, цвет текста/ошибки/лучей, радиус и максимальная ширина карточки, геометрия луча и мобильные отступы. Другие экраны и API не менялись, новых npm-зависимостей нет.

Оригинальные variable TrueType находятся в `frontend/src/assets/fonts/`. OFL-лицензии — в `frontend/public/assets/font-licenses/`; Vite копирует их в сборку, сервер раздаёт их вместе со шрифтами:

- [Manrope — Google Fonts](https://github.com/google/fonts/tree/main/ofl/manrope): `Manrope-Variable.ttf`, 164 700 байт, ось 200–800.
- [Golos Text — Google Fonts](https://github.com/google/fonts/tree/main/ofl/golostext): `GolosText-Variable.ttf`, 184 292 байта, ось 400–900.

Кириллица и реальная загрузка обоих шрифтов проверяются браузером. CSS использует font-display: swap; runtime-запросов к Google Fonts нет. После браузерного набора добавлена доставка OFL-файлов: проверены HTTP 200 и побайтное совпадение обеих лицензий с исходниками; имена содержимого JS/CSS остались теми же.

Физические телефоны, аппаратные GPU и ручной скринридер не проверялись.

История исправлений: первые layout-проверки выявили общий footer с автоматическими отступами; снимок также показал конфликт `.primary` с белой CTA. После исправления пройден весь набор. Сравнение с источником затем выявило неправильный цвет луча ошибки — hue-rotate заменён красным слоем. В одном повторе WebKit сообщил о прерванном fetch при тестовом reload сразу после смены URL; тест теперь ждёт фактическую карточку и networkidle перед reload, сохраняя строгий сбор ошибок. Последний полный прогон прошёл без ошибок.

Основной сервер получает тот же образ, что QA, локальным `docker tag dekanat-qa-app:latest dekanat-handoff-app:latest` и `docker compose up --no-build -d --wait`. Рабочая БД не сбрасывалась; reset используется только для `dekanat_e2e_test`. После возобновления работы Docker Desktop пришлось запустить заново; основной app/db восстановлены с сохранённым томом. QA после чистовой записи остановлен с сохранением тома; основной сервер оставлен работать.
