## Параметры надписи: запрос и измерение

| Запрошено | Измерено при 1440×900 |
|---|---|
| University / North / Campus, без точки | Три соответствующих span, без точки |
| Allura, локальный OFL-шрифт | Allura Regular, реальная загрузка TTF; OFL раздаётся по HTTP 200 |
| clamp(130px, 13vw, 190px) | 187,2 px; на 1000 px — 130 px |
| Белый, opacity около 0,2 | rgb(255,255,255), opacity 0,2 |
| line-height около 0,95 | 177,84 / 187,2 = 0,95 |
| Поворот −9°, origin слева по центру | Матрица соответствует −9°, origin 0 px / 266,742 px |
| Под карточками и голограммой | Фон z=0, фото z=1, голограмма z=2, логотип z=3 |
| Не перехватывать события/выделение/ARIA | pointer-events none, user-select none, aria-hidden true |
| Без собственной анимации | animation-name none; общее появление — только opacity |

Начала трёх слов проверены Range-измерением на 1000/1440: они внутри сцены и левее области карточек. Визуально крупные слова остаются задним слоем; окончания могут проходить под фото, как в макете.

## История исправлений

| Before | After | Why |
|---|---|---|
| [P1] Билет и подпись «Твой студенческий мир» | Подпись удалена, билет заменён 3D-шапочкой | Прямое уточнение владельца |
| [P1] Название кампуса — небольшой передний заголовок | Три больших строки Allura на заднем слое | Заданная композиция и декоративная роль |
| [P2] Две обычные гарнитуры | Manrope у формы, заголовка и обычного текста | Единый стиль; Allura используется только для отдельного фонового слоя |
| [P2] Пять более плотных фото | Четыре карточки и больший запас траектории | В восьми выборках реальные промежутки 46,94–133,85 px, фото не соприкасаются |
| [P2] Первый ракурс шапочки был слишком плоским | Увеличены тулья/наклон, уточнены золотая окантовка и кисточка | Повторный кадр и фокусная доска показывают объёмную узнаваемую форму |
| [P2] Оболочка сдвигала весь фон при входе | Убрана translateY, оставлена opacity | Соблюдение ограничения на появление надписи |

После повторного захвата открытых P0/P1/P2 относительно уточнённого задания не выявлено. Материалы и поза кодовой модели отличаются от фото; это ожидаемая адаптация вращающегося объекта, не заявление об идентичном меше.
